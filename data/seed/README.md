# Seed Dataset

This directory contains the synthetic infrastructure network for Ripple demos.

## Geography

The network is placed at real **Manipal, India** coordinates (approx. 13.35°N, 74.79°E)
so that it renders meaningfully on the MapLibre basemap.

## Contents

- `nodes.geojson` — Infrastructure nodes (power, water, hospital, road, telecom)
- `edges.geojson` — Dependency/connectivity edges between nodes

## Generation

Generated by `data/scripts/generate_synthetic.py`. The generator asserts:

1. The graph is connected (no isolated components)
2. Every hospital is reachable from at least one power substation

## Scale

~120 nodes, ~180 edges — small enough for smooth rendering, large enough for
meaningful cascading failure demos.
